Which rows exist

grain = SCHEMA_ID × CUST_SK × INSTR_ID × ISS_TYPE · RPTG_TYPE = 'WLT'

Customer schemas

Every (CUST_SK, SCHEMA_ID) in NPF_CUST_CSTM_SCHEMA

×

Customer's instruments + issue types

  • WPA_AC_POSITION: any calendar date
  • WPA_TRANSACTION: any date
  • (CUST_SK, INSTR_ID, AST_ISS_TYPE), UNION, distinct
⋈

Must exist in NPF_ASSET

Instrument not in NPF_ASSET → no row (same as the Oracle lookup)

• An instrument with several issue types gives one row per issue type; they are never combined. • A blank issue type ('') is treated as NULL: the row is kept and gets the default category in Step 2.

Standard category

RPTG_TYPE = 'WLT' AND ISS_TYPE = row issue type

→

✔ Row found

Standard super/sub code + desc = values from that row (even if a value is NULL)

✘ Row not found

Defaults: super 30 'Other Assets', sub 20 'Miscellaneous'

Country of risk

NPF_ASSET.CNTRY_RISK_DCDE → NPF_DECODE (DCDE_TYPE='CNTRY') desc. Not found → NULL; the row is still processed.

NO

Path 2: RULE_EVALUATION

The schema's active rules (RULE_STAT = 'A').
Inputs: standard super desc, standard sub desc, country-of-risk desc (from Step 2)

Each rule's conditions (NPF_CSTM_RULE_COND)

  • Field: CSTM_SUPCATG_DESC | CSTM_SUBCATG_DESC | CSTM_CNTRY_RISK_DESC
  • Operator: EQUAL | NOTEQUAL against RULE_FLD_VALUE
  • NULL input or value → condition is false
  • Any condition with LOGICAL_OPER='OR' → any true; otherwise all true
  • Rule with zero conditions → matches
1 rule matchesdesc = that rule's RULE_CSTM_*_DESC
>1 rules matchdesc = last match (highest RULE_SK); per column: last → first → standard
No matchdesc = standard descriptions
Codes (always, whatever the rule result)
CSTM_SUPCATG_CODE = <std sup>-S
CSTM_SUBCATG_CODE = <std sup>-<std sub>-S

Rule codes (e.g. 425) are not used; RULE_EVALUATION returns descriptions only.
