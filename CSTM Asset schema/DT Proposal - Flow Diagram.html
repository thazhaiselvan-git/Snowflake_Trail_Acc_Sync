WPA_CSTM_ASSET_SCHEMA_CATG → Snowflake Dynamic Tables

Replace Streams + Task + Stored Procedures with 4 dynamic tables that reproduce the Oracle npf_asst_typ_mgr + RULE_EVALUATION logic

2. What each table does

DT1 · Oracle: npf_asst_typ_mgr (6-arg)

WPA_CAS_ASSET_STD_DYN

Standard super / sub category and country description for each instrument. Defaults 30 Other Assets / 20 Miscellaneous when unmapped.
The only table that reads the asset source.
DT2 · Oracle: RULE_EVALUATION

WPA_CAS_RULE_PICK_DYN

Evaluates each schema's active rules once per distinct (super desc, sub desc, country), not per instrument. Keeps the first and last matching rule.
DT3 · Oracle: custom cursor

WPA_CAS_CSTM_ROW_DYN

The active custom override (END_DT IS NULL) for each schema + instrument, if one exists.
Final · Oracle: npf_asst_typ_mgr (11-arg)

WPA_CSTM_ASSET_SCHEMA_CATG_DY

One row per customer schema × instrument. Picks custom → rule → standard values and builds the -C / -S codes.
